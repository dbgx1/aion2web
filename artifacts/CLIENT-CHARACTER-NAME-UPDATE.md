# 客户端角色名更新

此更新让客户端的 MQTT 心跳上报当前角色名，供网页“在线客户端”列表显示。

1. 完全退出客户端。
2. 将更新包解压到 `aion2-client.exe` 所在目录，合并 `_internal` 文件夹并覆盖其中的 `mitm_ws_message_monitor.py`。
3. 重新启动客户端。若尚未识别角色，请重新登录游戏角色，让客户端捕获包含角色信息的登录请求。
4. 网页更新上线后，刷新客户端列表即可查看。未识别到名字时显示“未识别角色”。

源码运行方式：使用已更新的 `E:\project\aion2\client\mitm_ws_message_monitor.py`，重启客户端即可。

本次只在普通状态心跳中新增角色名，不新增角色 ID 上报；原有连接地址、房间和命令协议保持兼容。
