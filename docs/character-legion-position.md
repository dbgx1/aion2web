# 角色军团职位

角色字段由 `isLegionLeader` 改为 `legionPosition`，数据库列由
`is_legion_leader` 改为 `legion_position`。

| 原始值 | 职位 |
| --- | --- |
| 0 | 军团长 |
| 1 | 军团干部 |
| 2 | 军团成员 |
| 3 | 雇佣兵 |
| null | 未知或未采集 |

上传接口接受 `legionPosition` 或 `legion_position`，值可以是 0–3 的整数、
对应数字字符串或 null。省略字段保留已有职位，显式 null 清空职位。
布尔值和范围外数值会被拒绝。旧 `isLegionLeader` 字段单独上传会返回更新提示，
采集端需要改传真实职位，不能把旧布尔值直接转换成 0/1。

列表、按区服读取、重点跟踪和角色编辑均使用新字段；仅军团长筛选使用
`legion_position = 0`。页面显示原始值及职位名称，编辑表单可选择四种职位或未知。

发布时先执行 `0020_character_legion_position.sql` 数据库迁移，并协调发布新版服务
和采集端。迁移将历史军团长转换为 0，其余旧记录置为 null，因为旧字段无法判断
干部、成员或雇佣兵；这些记录需要重新采集。迁移会移除旧列，旧版服务不兼容。

已发布到 https://mmorpgchat.com，版本 `a995809e-3971-47f2-a223-df449020b5e4`。
线上迁移 0020 已完成且没有剩余迁移：共 123,005 个角色，其中 1,374 个军团长
转换为职位 0，121,631 个旧记录职位为 null。迁移前后角色总数一致。
首页与新版静态资源返回 200，未登录角色接口返回 401。采集端仍需改传新字段。
