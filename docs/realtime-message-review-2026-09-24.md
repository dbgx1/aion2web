# 实时消息审查与发布（2026-09-24）

## 当前聊天角色定时查询

- 仅查询当前打开的私聊角色；进入对话时立即查询，每轮完成后默认等待 60 秒。
- 可选择关闭、30 秒、60 秒、2 分钟或 5 分钟；切换角色时取消旧查询。
- 页面隐藏、网络断开、客户端断开时暂停，恢复后重新查询；公共频道和群发场景不触发。
- 自动与手动查询共用互斥控制，避免重复请求；失败逐步延长重试间隔，最长 5 分钟。

## 审查修复

1. 离线结果与在线结果都在新鲜期结束后显示为过期，避免把历史离线状态长期当作当前结果。
2. MQTT 必须完整确认所需主题后才允许发送；缺失、错误或被拒绝的订阅不会被当成就绪。
3. 消息保存使用合并后的消息集合，保留被 500 条事件日志挤出的未读回复；回执关联同时使用客户端与请求编号，避免跨客户端串联。
4. 执行结果未知的回执显示“发送结果未确认”，保存为待确认；读取旧记录也识别该状态，避免误报发送失败。
