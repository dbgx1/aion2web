# 重点跟踪（第一版）

角色列表、角色数据库和私聊标题的星标可加入或移出重点名单。消息侧栏 @全体 下方、角色资料页均有重点跟踪入口。

名单按登录账号隔离，通过角色数据库主键关联当前角色资料，包含优先级、跟进状态、备注、下次跟进时间。支持搜索、今天跟进、逾期、高优先级和状态筛选。已结束记录不计入今天/逾期筛选。时间按浏览器本地时区输入和显示。

移出只停用跟踪记录；再次加入保留已有备注和安排。在消息页打开聊天只选择收件人，不发送消息或启动 AI。第一版不含团队共享、自动提醒、跟进历史和 AI 摘要。

部署前应用 migrations/0012_character_tracking.sql。接口 /api/character-tracking 每次校验登录身份，忽略客户端传入的名单所有者。

验证：scripts/test-character-tracking.mjs 使用真实 SQLite 校验迁移、账号隔离、恢复记录、角色更新联查以及 HTTP 鉴权与序列化；scripts/test-character-tracking-ui.mjs 校验星标、编辑、失败恢复、筛选、刷新、移出再加入和打开聊天。
