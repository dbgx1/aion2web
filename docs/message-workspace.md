# 实时消息工作区优化

页面以“角色列表 + 当前对话”为默认布局。种族、区服和军团筛选折叠在列表顶部，筛选摘要常驻；全部角色/未读是列表过滤，群发和重点跟踪是固定操作入口，不随虚拟列表滚动。角色资料使用图标入口，星标直接跟踪。

AI 助手按需展开，大屏位于右侧，中等屏幕使用侧栏。收起不卸载助手、不清空输入或中断请求，顶部保留生成中和托管中状态。目标切换仍沿用已有请求失效机制。

手机在角色列表和对话之间切换，选中角色或群发后进入对话，顶部可返回列表。私聊 Enter 发送、Shift+Enter 换行；群发 Enter 换行、Ctrl/Command+Enter 发送，也可点击发送按钮。存在未结束群发任务时，快捷键和按钮均不允许重复启动。

验证：test-message-workspace-ui.mjs 覆盖折叠筛选、侧栏保留输入、双栏空间、手机切换、私聊和群发键盘操作；test-message-ai-scope.mjs 验证切换角色、筛选、占用和停止后旧 AI 工具无法发送。类型检查及生产构建通过。
