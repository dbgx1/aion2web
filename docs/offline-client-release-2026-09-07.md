# 离线客户端无法退出占用

根因：客户端中心仅列出在线客户端，而原退出入口依赖实时消息页中的已选在线客户端。离线角色的账号占用仍存在时，用户既无法打开其消息页退出，又因单账号只能占用一个客户端而无法进入其他客户端。

修复：客户端中心根据服务端占用列表独立展示本人“当前占用”与退出按钮，不依赖在线列表、所选客户端或 MQTT 连接。退出继续调用原鉴权 DELETE 接口，携带本人占用的客户端 ID 和 acquiredAt。增加请求超时、提交期间禁用按钮及始终可见的失败提示；未放宽其他账号或旧代次的释放权限。

验证：TypeScript、生产构建、真实 SQL 锁测试和 `test-client-lock-lifecycle.mjs` 浏览器回归通过。新增场景覆盖 A4 离线而页面选中 A1、释放失败后重试、正确释放 A4 后进入 A1，以及没有任何在线客户端时退出。生产客户端中心返回 200，主 JS 哈希与本地构建一致。

已发布版本：`c78d0c24-de3f-478c-8b85-e2fc524a15c1`，保留线上变量，无数据库迁移。用户刷新客户端中心后，在“当前占用”区域退出旧占用，再选择在线客户端进入实时消息。
